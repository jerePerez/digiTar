# Invitación Sofía #7 — Club Misterio

Proyecto React + Vite + Tailwind.

## Uso

```bash
npm install
npm run dev      # desarrollo
npm run build    # build de producción (carpeta dist/)
```

## Editar contenido

Todos los datos del evento (nombre, fecha, dirección, itinerario, links de WhatsApp/Maps)
están centralizados en `src/eventData.js` — no hace falta tocar los componentes para
reutilizar esta plantilla con otro festejado/a.

El tratamiento del nombre grande está en `src/components/NameHero.jsx`.
